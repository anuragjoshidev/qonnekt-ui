# Qonnekt UI

React components with Tailwind v4 tokens. Install with `npm i qonnekt-ui`, import `qonnekt-ui/theme.css`, and use path imports such as `qonnekt-ui/button`.

## Labels

- **Badge** — static status
- **Chip** — selectable
- **Tag** — removable

## Theming

Override CSS variables from `theme.css` in your app. Dark mode uses the `.dark` class on a parent (typically `<html>`).
